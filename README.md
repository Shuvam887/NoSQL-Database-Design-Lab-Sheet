# NoSQL Database Design – Lab Sheet 05

This repository contains practical exercises based on **Riak KV** and **Neo4j**.

### Topics Covered
- Riak KV installation and CRUD operations.
- Buckets, user sessions, and shopping carts.
- Database consistency and scaling.
- Neo4j graph database operations.
- Relationships, transactions, and Python connectivity.

### Technologies Used
Riak KV, Neo4j, Python, Cypher, and Linux.

**Purpose:** BCA academic practical work and learning.
